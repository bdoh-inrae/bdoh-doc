Utilisé par : Observatory, Site, Station, TimeSerie (via resourceType + resourceId)

       Distinct de Person.organization qui décrit l'appartenance institutionnelle.

### Observatory
Entité racine. Agrège des `Site` et porte la description du réseau de surveillance global.

| Champ         | Type           | Notes                                 |
|---------------|----------------|---------------------------------------|
| `id`          | UUID           |                                       |
| `name`        | string         |                                       |
| `description` | string         |                                       |
| `operator`    | → Organization | organisme gestionnaire                |
| `location`    | → Location     | emprise géographique globale          |
| `startDate`   | date           |                                       |
| `endDate`     | date           | null si actif                         |
| `url`         | string         | optionnel, site web du réseau         |
| `license`     | string         | licence des données (ex: ODbL, CC-BY) |


### Site
Subdivision géographique d'un `Observatory`. Regroupe des `Station` sur une entité physique cohérente (bassin versant, lac, zone humide…).

| Champ         | Type           | Notes                                             |
|---------------|----------------|---------------------------------------------------|
| `id`          | UUID           |                                                   |
| `name`        | string         |                                                   |
| `description` | string         |                                                   |
| `observatory` | → Observatory  |                                                   |
| `type`        | enum CV        | watershed / lake / wetland / aquifer / catchment… |
| `location`    | → Location     | géométrie (polygone ou point)                     |
| `area`        | float          | optionnel, en km²                                 |
| `operator`    | → Organization | optionnel si différent de l'Observatory           |


### Station
Point de mesure physique. Peut porter son propre équipement fixe (capteurs en continu, préleveurs automatiques installés à poste).

| Champ              | Type           | Notes                                          |
|--------------------|----------------|------------------------------------------------|
| `id`               | UUID           |                                                |
| `name`             | string         |                                                |
| `code`             | string         | code réseau unique (ex: "LBR-04")              |
| `description`      | string         |                                                |
| `site`             | → Site         |                                                |
| `type`             | enum CV        | streamgage / weatherstation / well / soilpit…  |
| `location`         | → Location     | point GPS                                      |
| `elevation`        | float          | altitude en mètres NGF                         |
| `operator`         | → Organization | optionnel                                      |
| `installationDate` | date           |                                                |
| `status`           | enum           | active / inactive / discontinued               |
| `equipment`        | → Equipment[]  | équipements fixes installés à la station       |


### Location / HistoricalLocation

| Champ          | Type     | Notes                                    |
|----------------|----------|------------------------------------------|
| `id`           | UUID     |                                          |
| `encodingType` | string   | `application/geo+json` (conformité STA)  | 
| `geometry`     | GeoJSON  | point, polygone ou linestring            |
| `crs`          | string   | ex: EPSG:4326                            |

| `validTo`      | datetime | pour HistoricalLocation, null si courant |

### ControlObservation

| Champ               | Type                | Notes                                             |
|---------------------|---------------------|---------------------------------------------------|
| `id`                | UUID                |                                                   |
| `timeSerie`         | → TimeSerie         |                                                   |
| `datetime`          | datetime            |                                                   |
| `type`              | enum                | field_blank / duplicate / standard / spike        |
| `result`            | float               |                                                   |

### TransferFunction / HistoricalTransferFunction
Fonction de conversion d'une mesure brute en valeur physique (ex: hauteur d'eau → débit via courbe de tarage). `HistoricalTransferFunction` trace les changements de courbe dans le temps.

| Champ            | Type           | Notes                                             |
|------------------|----------------|---------------------------------------------------|
| `id`             | UUID           |                                                   |
| `name`           | string         | ex: "Courbe de tarage Station LBR-04 v3"          |
| `station`        | → Station      |                                                   |
| `inputProperty`  | → Property     | variable en entrée (ex: hauteur)                  |
| `outputProperty` | → Property     | variable en sortie (ex: débit)                    |
| `type`           | enum           | rating_curve / linear / polynomial / lookup_table |
| `parameters`     | JSON           | coefficients ou table de valeurs                  |
| `validFrom`      | datetime       | pour HistoricalTransferFunction                   |
| `validTo`        | datetime       | null si courante                                  |
| `procedure`      | → Procedure    | méthode de construction de la courbe              |
| `operator`       | → Organization | optionnel                                         |

### Ce qui tient ensemble
La cohérence du modèle repose sur deux séparations claires : `TimeSerie` porte le **protocole analytique fixe** (ce qui rend les points comparables), `SamplingFeature` porte le **contexte terrain variable** (ce qui documente chaque prélèvement). Entre les deux, `limsReference` sur la `ValidatedObservation` ouvre la porte vers le LIMS sans l'absorber.

Deux objets transverses servent de ciment à l'ensemble : `Person` est référencé dans `SamplingFeature`, `ValidatedObservation`, `Transformation`, `Memory` et `Organization`. `Organization` est référencée dans `Observatory`, `Site`, `Station`, `Sensor`, `Equipment`. Ils n'appartiennent pas à une branche de la hiérarchie — ce sont des entités partagées du domaine.
